# 工作台协作架构审查后的修复

日期：2026-10-26。针对本机当前工作树实施；没有新增依赖、模型裁决层、数据库迁移或打包产物。本次没有提交或推送。

## 已完成

| 问题 | 修复及约束 |
| --- | --- |
| 首轮共同约定冲突决策后不能继续 | 所有角色完成规划后保存明确的规划完成标记；选择/保留方案后，宿主重新绑定已确认 Schema 并确认计划。重启后可沿用规划继续，不重新路由，不把失败的部分规划当作可执行计划。 |
| 下游单独修改时丢失未应用的上游文件 | 从前次宿主交接回执保留尚未应用的输入依赖；本轮没有唤醒的已完成角色也可提供成果。复用原文件检查、版本/hash、复制及过期判断。已应用成果继续从项目读取，不额外携带旧依赖。 |
| 插件截图/结构化结果被转换为空字符串 | 远程 MCP 返回文本、图片及结构化结果；嵌入文本资源可读，不主动抓取资源链接。暂不支持的内容明确反馈。保留远程服务器授权、凭据宿主管理、独占队列、取消与连接释放。 |
| 旧的相关记忆被最新 100 条截断 | 按角色和项目先过滤，流式评分，内存只保留 Top-K；无查询时按时间读取到限额即停止。待确认记忆和其他角色记忆仍不可读取。 |
| 成果页在其他操作忙碌时丢失自动加载 | 只读加载脱离共用操作锁，读取失败显示错误；角色/任务切换及文件选择后忽略过期响应。应用、下载、外部预览等用户操作仍沿用原控制。 |
| 工作台刷新状态重复读取完整历史 | `task:get` 增加可选 `includeTranscript:false`，工作台侧栏状态轮询使用该投影；默认行为不变。跳过活跃历史投影、会话文件打开与转录快照解析。 |
| 绑定角色技能在工作台不生效 | 新增按需发现的 `workbench_read_skill`，只读取当前角色任务快照中绑定的本地技能 Markdown 和参考 Markdown。路径、文件类型和大小检查位于宿主；不开放本地扩展、脚本、跨角色技能或命令权限。补齐受控只读 `tool_search` 白名单，使延迟工具可以被发现；实际调用仍独立检查权限。 |

## 没有改为并行规划

规划目前逐个调用并更新共同约定/提案，直接 `Promise.all` 会改变冲突语义。审查对此仅提出有条件的探索，尚未证明实际延迟收益。本次保留顺序规划，不引入共享状态竞态或重写规划框架。未来若需要并行，应先让角色返回互不写共享状态的提案，再由宿主统一合并并测量收益。
