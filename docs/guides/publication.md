# 公开仓库与隐私说明

[返回 README](../../README.md)

这个仓库以栖作当前源码快照初始化，和原先私有开发仓库的历史分开。公开内容包括桌面应用、核心运行时、契约与共享源码、测试、开发/打包脚本、锁文件，以及当前使用文档和品牌资源。

未收录：

- 旧私有 Git 提交历史、原型草稿及私人验收记录；
- 本机应用资料库、模型配置、API Key、OAuth 凭据、Cookie；
- 真实会话、角色私有记忆、用户项目工作副本；
- 安装包、node_modules、编译输出、机器诊断日志与临时预览令牌。

少量测试使用的路由标注样本和视频验收输入属于非私人测试夹具，随源码保留。需要真实模型的验收脚本要求使用者自行配置账号与本机资料路径，不包含作者凭据，不会在普通单元测试中自动运行。

README 截图在独立演示资料库中拍摄，未读取正式账号；角色、协作对话和记忆均为示例数据，不是模型效果评分。截图仅裁去系统标题区域并缩放，未替换界面内容。停用的定时示例没有实际执行。

发布前对公开文件和初始化后的 Git 历史进行密钥扫描，并额外检查凭证文件、数据库、私有资料路径与图片。扫描不能替代日常审阅；后续提交仍应保持这些边界。请勿在 Issue、PR、截图或日志中提交个人凭据。公开可见不等于已授予第三方任意使用许可；项目许可状态以 README 为准。

旧视频验收脚本需要本机 FFmpeg，以及适用的 Python 环境；可用 `PIH_FFMPEG_PATH` 与 `PIH_VIDEO_PYTHON_LIB` 指定路径。产品/视频验收中的样本资料仅用于测试输入，不代表真实市场数据或研究结论。真实模型验收会调用你自己配置的服务，不要在尚未检查环境时直接运行。
